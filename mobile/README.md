# PJN Tech HRMS — Mobile Application

## Overview
Android & iOS Mobile Application built with React Native and Expo for employee self-service, GPS check-in/out, hybrid work requests, and attendance history.

## Assigned Developer
- **Developer:** Karthick (Mobile Developer)
- **Tech Stack:** React Native + Expo (TypeScript), React Navigation, Lucide React Native

## Modules Covered
1. Mobile Authentication & Login
2. Employee Dashboard & Personalized Greeting
3. GPS In-House Attendance (100m Geofence Validation)
4. Apply Leave & Attendance History
5. Hybrid Attendance Requests

## Getting Started
```bash
# Install dependencies
npm install

# Start Expo dev server
npx expo start
```
